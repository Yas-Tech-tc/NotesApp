# Notes App

A simple web app to write and save notes, built with HTML, CSS, and JavaScript.

## Features
- Add new notes
- Delete notes
- Notes are saved in your browser (localStorage)

## Live Demo
[Check it out here](https://yas-tech-tc.github.io/NotesApp/)

## Built With
- HTML
- CSS
- JavaScript

## Run it locally
```bash
git clone https://github.com/Yas-Tech-tc/notes-app.git
cd notes-app
```
Then just open `index.html` in your browser.

## Notes
This was a small project to practice front-end basics and deploying with GitHub Pages.
